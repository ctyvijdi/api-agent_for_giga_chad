НАЗВАНИЕ ПРОЕКТА: "Умный городской сад" (Smart Urban Garden)

ОПИСАНИЕ ПРОЕКТА:
"Умный городской сад" - это инновационная модульная система для выращивания растений в городских условиях. Проект представляет собой автономные вертикальные сады, которые устанавливаются на стенах зданий, балконах и крышах. Система использует гидропонику и автоматизированное управление микроклиматом.

КАК РАБОТАЕТ ПРОЕКТ:
Система состоит из модульных панелей размером 1x2 метра, которые соединяются между собой. Каждая панель содержит 20 посадочных ячеек с датчиками влажности, температуры и освещенности. Растения выращиваются в питательном растворе без использования почвы. Насосная система автоматически подает воду и удобрения. Светодиодные лампы обеспечивают необходимое освещение. Все данные с датчиков передаются в облачный сервис.

ТЕХНИЧЕСКОЕ УСТРОЙСТВО:
- Модульные панели из переработанного пластика
- Гидропонная система с замкнутым циклом воды
- 20 датчиков на каждую панель (влажность, температура, pH, освещенность)
- Светодиодное освещение с регулируемым спектром
- Насосная система мощностью 50 Вт
- Контроллер на базе Raspberry Pi
- Wi-Fi модуль для передачи данных
- Солнечные панели для автономного питания
- Резервуар для воды объемом 100 литров

ЦЕЛЬ И НАЗНАЧЕНИЕ:
Проект создан для решения проблемы нехватки зеленых насаждений в городах. Основные цели:
1. Обеспечение городских жителей свежими овощами и зеленью
2. Улучшение экологической обстановки
3. Создание эстетически привлекательных зеленых зон
4. Образовательные цели для школ и университетов
5. Снижение углеродного следа за счет локального производства продуктов

ПРЕИМУЩЕСТВА ПРОЕКТА:
- Экономия воды до 90% по сравнению с традиционным земледелием
- Выращивание растений круглый год независимо от сезона
- Компактность и модульность установки
- Автоматизация ухода за растениями
- Возможность удаленного мониторинга через мобильное приложение

ОГРАНИЧЕНИЯ ПРОЕКТА:
- Высокая начальная стоимость установки
- Необходимость регулярного технического обслуживания
- Зависимость от электропитания (частично решается солнечными панелями)
- Ограниченный выбор культур для выращивания
- Требуется подключение к интернету для полной функциональности
