# Задание: Разработка агента-автоответчика для проекта

## Цель проекта
Создать интеллектуального агента-автоответчика, который общается с пользователем и отвечает на его вопросы, опираясь исключительно на текстовое описание проекта. Агент должен работать в терминале и поддерживать диалог в режиме реального времени.

## Задачи проекта

### 1. Создать текстовое описание проекта (файл project_info.txt)
Файл должен содержать:
- Название проекта
- Описание того, как работает проект
- Техническое устройство проекта
- Цель и назначение проекта
- Ссылки на дополнительные материалы (фотографии, исследования, публикации)
- Структурированную информацию для удобного анализа

### 2. Разработать агента-автоответчика на Python
Агент должен уметь:
- Загружать текст описания проекта из файла
- Принимать вопросы от пользователя в консоли
- Анализировать вопрос и искать ответ в описании проекта
- Отвечать на вопросы, используя GigaChat и контекст проекта
- Сообщать, если информация отсутствует в описании
- Поддерживать историю диалога для контекстных вопросов

### 3. Реализовать интерфейс взаимодействия
Интерфейс должен включать:
- Приветственное сообщение с названием проекта
- Консольный ввод вопросов
- Вывод ответов в читаемом формате
- Индикацию источника информации (из описания или общий ответ)
- Команду exit для выхода
- Команду help для подсказки

## Требования к реализации

### Технические требования:
- Python 3.8+
- Библиотеки: gigachat, python-dotenv
- API ключ GigaChat в файле .env
- Чтение данных из project_info.txt в кодировке UTF-8

### Функциональные требования:
- Агент должен отвечать строго на основе информации из описания проекта
- Если информации нет в описании, агент должен честно об этом сообщить
- Сохранять контекст диалога для уточняющих вопросов
- Не выдумывать факты, которых нет в описании
- Корректно обрабатывать ссылки на дополнительные материалы
- При ответе указывать, из какого раздела описания взята информация

## Критерии оценки
- Точность ответов на основе описания проекта
- Способность отличать информацию из описания от общих знаний
- Качество системного промпта для ограничения контекста
- Устойчивость к ошибкам (некорректный ввод, проблемы с файлом)
- Читаемость кода и наличие комментариев
- Удобство интерфейса для пользователя

## Дополнительные рекомендации
- В системном промпте чётко укажите, что агент должен использовать только информацию из описания
- Добавьте команду info для повторного вывода описания проекта
- Реализуйте проверку наличия файла с описанием перед запуском
- Используйте форматирование текста для улучшения читаемости ответов
- Добавьте обработку пустых вопросов и повторяющихся запросов
